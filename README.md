# juniorliu95.github.io

Personal site of Junyu Liu: https://juniorliu95.github.io/

A static page: `index.html`, `style.css` and `assets/`. No build step. Edit and push, and GitHub Pages serves it.
To use a photo, add `assets/profile.jpg` and replace the monogram `<div class="portrait">` in `index.html`. A comment in `style.css` shows the line to use.
